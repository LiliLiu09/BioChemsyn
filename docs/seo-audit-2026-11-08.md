## Public baseline

- `/en`: HTTP 200, English title and self-referencing canonical.
- `/robots.txt`: HTTP 404.
- `/sitemap.xml`: HTTP 404.
- Product route source used the generic title `Product details`.
- Language-switch links pointed through `/api/locale` rather than directly to language-specific pages.
- Homepage category links used query filters rather than dedicated collection pages.

This establishes crawlability issues, not Google's actual indexed-page count. Search Console was not connected or inspected.

## Changes

- Added robots.txt with a sitemap reference and exclusions for admin, API, cart and search routes.
- Added a dynamic bilingual sitemap based on published CMS content; unavailable English products/articles are excluded from English URLs. No fabricated modification dates.
- Replaced language-switch hrefs with direct Chinese/English URLs, preserving search/hash on normal clicks. Removed cookie-dependent redirection of `/`, so explicit page URLs have a stable language. The legacy language endpoint remains compatible.
- Added product-specific English and Chinese titles/descriptions, canonical and language alternates, Open Graph/Twitter metadata, and Product JSON-LD. Product names, identifiers and formulae come from existing CMS records. No invented prices, ratings or availability.
- Added unique English overview/selection content, enquiry contact and related-product links to the 20 selected products below. Existing CMS descriptions remain intact.
- Added five crawlable bilingual category routes with English category introductions, selection guidance, enquiry details, collection markup and server-rendered product links. Linked them from the catalog, homepage categories and product breadcrumbs.
- English unavailable-product fallback pages are noindex. Product search results are noindex; legacy core category filters canonicalize to their collection URL.
- English CAS/formula fields no longer expose Chinese placeholders.
